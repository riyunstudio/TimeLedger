# TimeLedger 產品需求文檔 (PRD)

## 1. 產品概述

**TimeLedger** 是一個教師中心化多據點排課平台，專為台灣教育培訓產業設計，支援 LINE 生態系整合。

### 1.1 目標市場
- 台灣教育培訓中心
- 私人補習班
- 瑜伽/舞蹈工作室
- 音樂教室

### 1.2 核心價值主張
- **教師端**：LINE 點開即用，無需註冊帳密
- **中心端**：完整排課管理、例外審核、智慧媒合

## 4. 使用者流程

### 4.1 教師首次登入流程

```
1. 開啟 LINE → 搜尋官方帳號
2. 點擊「開始使用」或「綁定」
3. 開啟 LIFF 頁面 → 自動取得 LINE id_token
4. 後端驗證 id_token → 建立/更新 teacher 資料
5. 顯示個人檔案頁面 → 填寫基本資料
6. 綁定完成，可使用所有功能
```

### 4.2 排課流程

```
1. 管理員建立排課規則
   • 選擇班別 (Offering)
   • 選擇老師 (Teacher)
   • 選擇教室 (Room)
   • 選擇星期與時間
   • 設定日期範圍

2. 系統驗證
   • 檢查老師時段重疊
   • 檢查教室時段重疊
   • 檢查緩衝時間

3. 驗證通過 → 建立排課規則
4. 規則展開 → 產生具體 Session
```

### 4.3 例外申請流程

```
1. 教師提交例外
   • 選擇類型：請假/調課/代課
   • 選擇日期
   • 填寫原因

2. 系統 Soft Validation
   • 檢查是否超過截止日

3. 產生例外記錄 → 狀態 PENDING

4. LINE 通知所有管理員

5. 管理員審核
   • 核准：Hard Validation → 通過 → 執行異動
   • 拒絕：填寫理由 → 通知教師
```
